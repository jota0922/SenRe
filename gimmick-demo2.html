New Tech

ここ1〜2年で主要ブラウザに載った最新のHTML/CSS機能だけを、本サイトと同じ世界観で試作しました。ほとんどが JSほぼ不要 で動きます。気に入ったものを教えてください。

/ 01

Scroll-driven Animation CSS only

上部の進捗バーはページのスクロール量に、下のカードは各自が画面に入った量に連動します。今までJS必須だった演出が animation-timeline: scroll() / view() だけで完結。スクロールして確認してください。

/ 02

Popover API + Anchor almost no JS

popover 属性と anchor() だけで、ボタンに張り付くツールチップ／ドロップダウンが作れます。トップレイヤー表示・外側クリックで自動クローズ・画面端では自動反転。ライブラリ不要です。

/ 03

Exclusive Accordion HTML only

<details name="faq"> と 名前を揃えるだけで、片方を開くともう片方が自動で閉じる排他アコーディオンに。開閉の高さアニメは interpolate-size で滑らかに。JSゼロのFAQです。

SenReとは？

エイム系コミュニティの大会・ランキングプラットフォームの試作です。このFAQ自体がHTMLだけで動いています。

参加方法は？

この項目を開くと、上の項目が自動で閉じたはずです。name属性を共有しているためです。

費用はかかる？

無料です。開閉のアニメーションは height:auto へ補間できる最新CSSで実現しています。

/ 04

Container Queries CSS only

画面幅ではなく「親要素の幅」でレイアウトを切り替えます。@container によって、同じ部品をサイドバーでも本文でも最適表示。下のボックスの右下をドラッグして幅を狭めると、横並びが縦積みに変わります。
